= Test AsciiDocRoles Specification

This is a test AsciiDoc specification (native role syntax) for integration testing.

== Authentication

[role="requirement", id="auth.login"]
--
Users MUST provide valid credentials to log in.
--

[role="requirement", id="auth.session"]
--
Sessions MUST expire after 24 hours of inactivity.
--

[role="requirement", id="auth.logout"]
--
Users MUST be able to log out and invalidate their session.
--

== Data Validation

[role="requirement", id="data.required-fields"]
--
All required fields MUST be validated before processing.
--

[role="requirement", id="data.format"]
--
Email addresses MUST be validated against RFC 5322 format.
--

== Error Handling

[role="requirement", id="error.codes", status="deprecated", tags="legacy,audit"]
--
All errors MUST include a machine-readable error code.
--

[role="requirement", id="error.messages"]
--
Error messages MUST be human-readable and actionable.
--
